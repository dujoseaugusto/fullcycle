Cep-climate — Test Requests

Esta página reúne exemplos de curl que você pode colar no terminal ou importar para o Postman.

1) CEP válido (via Service A)

Retorna 200 com cidade e temperaturas.

curl -X POST -H "Content-Type: application/json" -d '{"cep":"37890000"}' http://localhost:8080/zipcode
Copiar

2) Formato inválido (tamanho != 8) — espera 422

curl -X POST -H "Content-Type: application/json" -d '{"cep":"12345"}' http://localhost:8080/zipcode -i
Copiar

3) Campo não-string (número) — espera 400

curl -X POST -H "Content-Type: application/json" -d '{"cep":12345678}' http://localhost:8080/zipcode -i
Copiar

4) CEP formato correto mas não encontrado — espera 404

curl -X POST -H "Content-Type: application/json" -d '{"cep":"00000000"}' http://localhost:8080/zipcode -i
Copiar

5) Chamar Service B diretamente

curl -X POST -H "Content-Type: application/json" -d '{"cep":"37890000"}' http://localhost:8081/zipcode -i
